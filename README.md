# 🎓 Computer Science Student Bot

بوت Telegram لمكتبة قسم علوم الحاسوب.

## الفكرة
- 📚 المواد
- 🌳 شجرة المواد
- 📚 المراجع والكتب
- 📝 الشيتات
- 📋 الأسئلة
- 🔍 البحث عن مادة
- 👑 لوحة إدارة لإضافة المحتوى

## التشغيل
1. ثبتي Python 3.11 أو أحدث.
2. افتحي Terminal داخل المجلد.
3. شغلي:
   `pip install -r requirements.txt`
4. انسخي `.env.example` إلى `.env`.
5. ضعي Bot Token في `BOT_TOKEN`.
6. ضعي Telegram ID الخاص بك في `ADMIN_IDS`.
7. شغلي:
   `python bot.py`

## ملاحظة
هذه نسخة بداية منظمة. الخطوة التالية هي إدخال شجرة المواد الموجودة في صورة القسم بالكامل، ثم تحويل إضافة الملفات إلى لوحة أزرار سهلة بدون أوامر.
